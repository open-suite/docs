# Manage storage quotas

File storage is **Nextcloud**. Quotas are set per user or per group.

1. Sign in to the portal as a Nextcloud admin.
2. Open **Files → Settings → Administration → Users** (or go to `/settings/users`).
3. Find the user and set a value in the **Quota** column (e.g. `5 GB`), or pick a
   preset.
4. To apply a default to everyone, set **Default quota** at the top of the users
   page.
