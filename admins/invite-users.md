# Invite a user

Users live in **Keycloak** (the SSO identity provider). Adding them there grants
access to every app in the suite.

1. Go to `https://id.<your-domain>` and sign in as an admin.
2. Select the **mijnbureau** realm → **Users → Add user**.
3. Enter username and email, then **Create**.
4. Open the **Credentials** tab → **Set password**, leave **Temporary** on so the
   user resets it at first login.
5. The user can now sign in at the portal with SSO.
