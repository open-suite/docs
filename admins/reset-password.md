# Reset a user's password

1. In **Keycloak**, open the **mijnbureau** realm → **Users**.
2. Search for the user and open their record.
3. Go to **Credentials → Reset password**.
4. Enter a new password, keep **Temporary** on, and **Save**.
5. Tell the user to sign in and set their own password.

To force a reset without setting one, use **Credentials → Reset Actions →
Update Password** and click **Send email**.
