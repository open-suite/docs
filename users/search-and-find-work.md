# Search and find work

Use search when you know part of a title, file name, contact, or conversation.

## Search from Files

Open **Office → Files** and use the search field at the top left.

![Files recent view](/img/users/files-recent.png)

Search for distinctive words. `budget` is better than `doc`; `Q3 plan` is better
than `plan`.

## Use Recent

Open **Recent** when you worked on the item recently but do not remember its
folder.

## Use Favorites

Mark important files as favorites when you return to them often.

![Files favorites view](/img/users/files-favorites.png)

Favorites are useful for team plans, recurring meeting notes, and active project
folders.

## Search from the portal

The portal widgets show recent Docs and NextCloud files. Use the widget search
fields when you want to reopen something from the home page.

## If search fails

Try these checks:

1. Search for a different word.
2. Check **Recent**.
3. Check **Shares**.
4. Ask the owner whether the file is shared with you.
5. Check **Deleted files** if you owned it.
