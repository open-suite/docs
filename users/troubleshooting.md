# Fix common problems

Use these checks before asking an admin for help.

## An app asks me to sign in again

Return to `https://bridge.demo.opensuite.online/`, then open the app from the
top navigation. This refreshes the single sign-on session.

## I cannot find a document

1. Open **Office → Files**.
2. Search for a word from the file name.
3. Check **Recent**.
4. Check folders shared with your team.
5. Check **Deleted files** if the document may have been removed.

## The Meet camera or microphone does not work

1. Check the browser permission icon in the address bar.
2. Allow camera and microphone access for Meet.
3. Close other apps that may be using the camera.
4. Rejoin the room.

## A calendar event has no meeting link

Open the event and click **Add Meet link**. Save the event after the link appears
in the location field.

## A shared link does not open

Ask the owner to check the sharing settings. Internal work should usually be
shared with your user or group rather than through a public link.
