# Use Open Suite on mobile

Use the browser on your phone for quick checks, meeting joins, and file access.
Use a desktop browser for heavy document editing.

> **Screenshot limitation:** the repository does not contain a current mobile
> capture. These steps avoid device-specific icon positions rather than showing
> an old or reconstructed mobile interface.

## Good mobile use cases

- Check calendar details.
- Join a Meet call.
- Read or send mail.
- Read a shared document.
- Download a file.
- Reply to a chat message.

## Open the portal

Go to `https://bridge.demo.opensuite.online/` and sign in. Use the navigation
menu or the dashboard cards to open the app you need. The current app groups are
the same as on desktop: **Home**, **Mail**, **Chat**, **Meet**, **Office**,
**Calendar**, and **More**.

Under **Office** you can open Documents, Spreadsheets, Presentations, Diagrams,
and Files. **More** contains Tables, Wiki, and Contacts.

## Join meetings from mobile

Open the Calendar event or Meet link. Allow camera and microphone permissions
when the browser asks. If you denied them earlier, use the browser's site
controls and the phone's privacy settings before rejoining.

Use headphones when possible. They reduce echo and make meetings easier for
everyone.

## Use files and chat

- In Files, tap a file name to preview it. Use the row's action menu for sharing
  or downloading.
- Chat stays in the mobile web interface. Use the room list or Search to open a
  conversation.
- Keep the browser open until an upload finishes.

## Editing on mobile

Small edits are fine on mobile. For structured document work, presentations, or
large tables, switch to a laptop or desktop.

## Sign out on a shared device

Return to the portal and choose **Log out**. Closing a tab does not end the
single sign-on session.
