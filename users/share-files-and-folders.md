# Share files and folders

Use sharing when another person needs access to a file without sending a copy.

## Start from Files

Open **Office → Files**, then find the file or folder.

![File row with share action marked](/img/users/files-share-start-annotated.png)

## Share with a person or group

1. Click the share icon on the file row.
2. Search for a person or group.
3. Select the result.
4. Choose whether they can view or edit.
5. Close the panel after the right people are listed.

Use named people and groups for internal work. This keeps access auditable and
easy to remove later.

## Share a folder

Share a folder when the same group needs access to every file inside it. New
files added later inherit the folder sharing.

Use project folders for project teams. Avoid sharing your top-level Files area.

## Stop sharing

Open the sharing panel again and remove the person, group, or public link. The
file stays in your Files app, but the removed recipient loses access.

## Good sharing habits

- Share the folder, not every individual file, when the same group needs all of
  the work.
- Use edit access only for people who should change the file.
- Remove access when a project ends.
- Do not use public links for sensitive internal work.
